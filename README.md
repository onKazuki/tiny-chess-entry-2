A chess engine in 4 KB of Python for the [tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01): 0x88 board, tapered piece-square evaluation, alpha-beta/PVS with quiescence, transposition table, killers, history, null-move pruning and LMR, fixed 80,000-node search.

Run: `python3 main.py` (with `MAKEFUN_ENV_URL` set).
